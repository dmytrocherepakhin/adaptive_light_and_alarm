# Adaptive Light and Alarm

Навчальний проєкт на ESP32-S3: регулювання освітлення за показами фоторезистора та світлова сигналізація після натискання кнопки.

## Обладнання та підключення

- ESP32-S3-DevKitC-1, фоторезистор, транзистори, світлодіоди, кнопка та резистори.
- Зовнішнє живлення.
- GPIO2 — аналоговий сигнал фоторезистора.
- GPIO16 — білий світлодіод; GPIO17 — жовтий сигнальний світлодіод.
- GPIO18 — PWM-вихід; GPIO21 — кнопка (активний рівень HIGH, зовнішня підтяжка до GND).

[Схема підключення](docs/images/Adaptive_light_and_alarm_scematic.jpg)

## Поточна логіка

- Зчитування входів.
- ADC 2000–4000 пропорційно перетворюється на PWM 5–255 (приблизно 2–100%), частота — 5 кГц. Поза діапазоном значення обмежується.
- Білий світлодіод увімкнений при ADC < 3500.
- Після натискання кнопки жовтий світлодіод перемикається кожні 500 мс. Сигналізація залишається активною до перезапуску.

## Збірка та запуск

Відкрити проєкт у PlatformIO (Arduino framework), виконати **Build**, потім **Upload**. Швидкість Serial Monitor — **115200 бод**. Конфігурація міститься у `platformio.ini`.
